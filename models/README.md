# Model Weights Are Not Included

This directory intentionally contains documentation only. Model weights, native
runtime bundles and caches are excluded for size, licensing/distribution review
and GitHub practicality. Obtain each component separately under its own terms.

Roles: Groq primary reasoning, local Qwen fallback, Parakeet STT, B4/Qwen TTS and
optional Moondream vision. See [docs/MODELS.md](../docs/MODELS.md) for configuration
boundaries. Never place API keys or personal voice recordings in this repository.
