# Excluded Categories

- Model weights/checkpoints and inference distributions: size, licensing and platform setup; see models/README.md.
- Virtual environments, vendored Python distributions, node_modules and caches: install dependencies separately.
- Personal/protected memory, private SELF/profile state, conversation/session logs, telemetry and location/activity history: privacy. Only implementation code is included.
- Credentials, .env and keys: never redistributable. .env.example contains placeholders only.
- Rollback/promotion snapshots and older copied overlays: duplicate runtime history, not the maintained review boundary.
- Generated user artifacts, recordings, screenshots and runtime evidence: private or unnecessary; no screenshot was captured.
- Avatar/model textures and preview images: not redistributed without a separate asset-rights/privacy review. Procedural hologram source remains.
- Session collection scripts and machine-only visual diagnostics: irrelevant to judge review.
- Runtime binaries/installers/compiler distributions: platform dependencies, not source.
